# Authoring — draft, evidence, confirm

Core guidance for `authoring` skills: `blogy · brandy · diagramy · narraty`.

Reference this page from authoring skills instead of restating shared rules.

## Authoring draft evidence confirm

- **Real inputs, no invention.** Claims, stats, links, quotes, and media come
  from real sources. Measure or omit; never fabricate.
- **Draft before publish.** Produce a reviewable artifact/draft first. Owner
  confirmation before publish/deploy/external share unless the active workflow
  explicitly says otherwise.
- **Artifacts are traceable.** Keep source list, prompt/inputs, or generation
  parameters when useful for rerun/review. State output path and format.
- **Scope stays in the medium.** Authoring skills create content/assets; they do
  not silently change unrelated app behavior, contracts, or registries.
