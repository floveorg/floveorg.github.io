## LANG01 decision

All flove content — apps, webs, docs and code — is written in English. The
Spanish exceptions are `liberada`, `futbolia` and `dinámicas electrónicas`.
Bilingual pages name one source language; the other language is a translation,
not a second source. A page that mixes source languages is a defect, not a
style choice.
