jsonyJSON backbone routine · flove

One commit in apps/ → one pending JSON update.

jsony checks the shared files that connect apps, routing, Appy and the export envelopes. Commits only queue changes; a manual or scheduled --changed turn writes the reviewable pending report.

the routine
1

Commit touches apps/

The post-commit hook checks the changed paths. No apps/ change → it exits quietly.

↓
2

Queue only

--record --soft appends the changed files to tools/jsony-state.json. No full check, no block.

↓
3

--changed → four checks

routing.jsonapp ids + URLs exist
Appy APP_ROUTINGids + categories match
export envelopesflove-portrait · flove-profile
↓
4

Pending report

tools/jsony-pending.md for review and tools/jsony-pending.json for a later agent pass. The processed commit becomes the watermark.

↓
5

Review → apply → align

Fix routing, update the Appy snapshot, regenerate the catalog, then run exporty on the changed app. Re-run with --strict until clean.

what is checked

Critical blocks strict

  • app manifest missing from routing.json
  • routing URL does not resolve on disk
  • APP_ROUTING missing / extra / wrong category
  • appy export envelope lost flove-profile, flove-routing/3, appsPlayed, flove-portrait/1 or flovePort

Advisory review

  • an app with fields has no flovePortrait / flovePort
apply order
  • Read tools/jsony-pending.md.
  • Add/fix the routing.json entry; field trees via tools/extract-fields.py --apply.
  • Update the APP_ROUTING snapshot in apps/appy/index.html.
  • Run exporty on the changed app.
  • Re-run jsony_check.py --strict; delete the pending files when clean.
