# questy-flove — the flove-app interview

Uses the main process in [`questy/SKILL.md`](https://flove.org/development/standards/skills/questy/SKILL.md) and adds the flove-app interview:
questioning the owner **as a user** of the apps and exporting a
`flove-profile` JSON. Never the maker. Questy owns and explains the hats; this skill only adds
the flove layer.

```text
pick app(s) → set Flove influence (0–5) → answer typed batches
→ map answers to profile slots → export the JSON
```

The questions are the app's own reflective set (Goddy: "Do you think there is a
goddess?", "Do you think she sees us?"); the answers are positions in the owner's
profile.

## Apps and category colours

Apps and fields: `tools/routing.json` — canonical. The page is regenerated by
`tools/dev/build-questy-flove-data.py`; the catalogue is cached in `localStorage`
(`questy-flove-catalog` + `-at`).

One colour per category, never per app or slot: Inside → orange (heart), Mating →
yellow (optimism), Linguistics → green (creative), Social → blue (make), Economy →
indigo (facts). An app's own accent never changes it.

## Flove influence

The gauge runs **0–5**: `0` None · `1` Little · `2` Some · `3` Blend · `4` Much ·
`5` Very much.

### The ladder — what the degree changes

| # | Level | The batch is built from |
|---|-------|-------------------------|
| 0 | None | the project's docs only; flove is invisible |
| 1 | Little | one flove touch (a term or a category hat); no field names |
| 2 | Some | flove vocabulary where it helps + category hats; no app fields |
| 3 | Blend | the chosen app's field-info page, quoted in its category hat |
| 4 | Much | related-app `kind:input` fields as data; `cross[]` prioritises |
| 5 | Very much | the whole model — every app, all `kind:input` fields and all cross links; flove sets the shape of each question |

At 3 and 4, related apps are the apps in the same category (`apps[]` filtered by
`category`), all wearing that category's hat; at 5 the whole catalogue is in
play. Name fields by their catalog label. Never lift `display`, `action` or `nav` slots; an app with no `kind:input` slots
uses its authored reflective set — never invent fields.

### Intake

The degree comes from the invocation (below); if none is given, ask once. Wizy
(`https://flove.org/apps/sys/wizy/`) is an additional source of flove information
— consult it for app and field suggestions when it helps; never as answers.

### Influence-named invocations

The degree can travel in the invocation name: `questy-flove-0` = **None**,
`questy-flove-1` = **Little**, `questy-flove-2` = **Some**, `questy-flove-3` =
**Blend**, `questy-flove-4` = **Much**, `questy-flove-5` = **Very much**. The number
always equals the degree in the gauge — never offset it. Plain `questy-flove`
opens with no degree selected and lets the owner choose.

The section shows categories and Voice from **1+**. Category weights and Voice are
tri-state `0/1/2` (default `0`, `2` = full emphasis). The **Agent precision** block
under the controls is copyable and mirrors the prompt.

Three lighter embeds: **Compact** (gauge + Voice), **Minimal** (gauge + one-line
description), **Micro** (gauge only) — Full for onboarding, Compact for sidebars,
Minimal for inline cards, Micro for mobile and footers.

## Voice — Love · Joy · Wisdom

Each is `0/1/2` (`1` light tint, `2` full emphasis); all three combine, and the
texts travel into the profile export.

- **Love** — emotional continuity at scale: remember what the person cares about,
  speak with care, never sentimentality. Inside apps: Souls · Goddy · Astry ·
  Hacky; fields: Focus · Self-reflection · Traditions · Likes / Dislikes.
- **Joy** — earned delight: wit and surprise that sharpen the work instead of
  distracting. Mating apps: MyFamily · Daty · Trusty; fields: Friendship · Regular
  care & affection · Trustful signals.
- **Wisdom** — measured judgement over speed: name trade-offs, hold complexity,
  leave room for doubt. Social apps: Socy · Blogy · Browsy · Nety; fields:
  Categories · Parent category · Related categories · Circles · Posts.

## Output

A **`flove-profile` JSON**: `appsPlayed` with the answers
keyed by the app's own questions or input fields, plus `influence`, `voice` and the
visibility block.

```json
{
  "kind": "flove-profile",
  "version": 1,
  "appsPlayed": [{ "app": "Daty", "colour": "#ffd84d", "answered": { "Children": "Yes" } }],
  "influence": 3,
  "categoryWeights": { "inside": 2, "mating": 1, "ling": 0, "social": 0, "economy": 0 },
  "voice": { "love": 1, "joy": 2, "wise": 0 },
  "visibility": { "content": "mynet", "resources": "mynet", "profile": "private", "scores": "private" }
}
```
