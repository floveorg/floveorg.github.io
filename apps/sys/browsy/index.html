Use cases inside Browsy

Browsy hosts the local data layer. Each app keeps its own JSON; Browsy manages the record and its class. MyFamily is the L use case; Goddy is a mixed P + L + S case with more public output.

P → L · private by default

MyFamily

Each added person starts as P (private); Wizy reads it locally. Sharing to a peer or group creates an L projection; S is only a minimal public card. The profile is the 7×5 MyFamily matrix → 5 type percentages. MyNet builds flat local groups from these same people.

L · MyFamily profile

MyNet

Verified Telegram enables MyNet in appy-basic. It uses the MyFamily 7×5 profile → 5 type percentages, kept as L when shared; Personal stays P. Groups are flat and owner-managed; pick people, set roles and a projection. Public publishing needs verified Telegram and is deferred.
